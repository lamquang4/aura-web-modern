# Backend Node.js

## Cài đặt

Khởi tạo project:

```
npm init -y
```

Cài đặt dependencies:

```
npm install
```

## Chạy project

**Development**

```
npm run dev
```

**Production**

```
npm start
```

## Thư viện sử dụng

| Thư viện           | Mô tả                                    |
| ------------------ | ---------------------------------------- |
| Express            | Xây dựng REST API                        |
| Dotenv             | Quản lý biến môi trường (.env)           |
| Cors               | Cho phép Frontend gọi API từ domain khác |
| Mongoose           | Kết nối và thao tác với MongoDB          |
| Bcrypt             | Mã hóa mật khẩu                          |
| JsonWebToken (JWT) | Xác thực người dùng bằng token           |
| Multer             | Upload file                              |
| Axios              | Gọi API bên ngoài                        |
| Express Validator  | Validate dữ liệu đầu vào                 |
| Morgan             | Logging request                          |
| Nodemon            | Tự động restart server khi code thay đổi |
